# Software Requirements Specification (SRS) — Kelompok 12

## Tentang Project
Repository ini berisi dokumen Software Requirements Specification (SRS) yang dibuat oleh Kelompok 12 sebagai dokumentasi kebutuhan dan acuan dalam pengembangan perangkat lunak.

## Tujuan
Sistem ini bertujuan untuk membantu proses pengelolaan data dan informasi secara lebih terstruktur, efektif, dan mudah digunakan, serta mengurangi kesalahan yang dapat terjadi pada proses manual.

Dokumen SRS digunakan sebagai pedoman untuk memastikan sistem yang dikembangkan sesuai dengan kebutuhan pengguna.

## Fungsi Sistem
Fungsi utama sistem meliputi:

1. Mengelola dan menyimpan data secara terstruktur.
2. Mempermudah pengguna dalam mengakses dan mengelola informasi.
3. Membantu proses pengolahan data agar lebih efektif.
4. Mengurangi kesalahan dalam pengelolaan data.
5. Menjadi acuan dalam proses pengembangan dan pengujian sistem.
